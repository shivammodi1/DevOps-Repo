# Run Docker Image Inside a Container
- Click on run button to start a new container
- In the "Image" field, enter the name of the Docker image you want to run inside the container.
- In the "Command" field, enter the command to run Docker inside the container. For example, you can use `docker run <image-name>` to run a specific Docker image.
- select **optional settings** and than write the container name , port mapping and volume mapping if needed.
- You can provide random port using 0 in the host port field. Or you can specify a specific port number.
- Click on the "Run" button to start the container with Docker running inside it.
- Once the container is running, you can access it using the terminal or command line interface.
