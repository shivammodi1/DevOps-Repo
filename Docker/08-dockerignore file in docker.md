# .dockerignore File in Docker

## Why we need .dockerignore file?
- So The working of **.dockerignore** file is similar to **.gitignore** file.
- It is used to ignore files and directories when we build a Docker image.
- This helps to reduce the size of the Docker image by excluding unnecessary files and directories.
- It also helps to improve the build time of the Docker image by reducing the number of files that need to be copied to the Docker image during the build process.
