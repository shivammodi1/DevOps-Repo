# Types Of Cloud

---

- There are three main types of Cloud computing:
  1. **Public Cloud**: Services are delivered over the public internet and shared across *multiple organizations*. Examples include Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).
  
  2. **Private Cloud**: Services are maintained on a private network, dedicated to a *single organization*. This provides greater control over data and security. Examples include on-premises data centers or private cloud services from providers like VMware or OpenStack.

  3. **Hybrid Cloud**: A *combination of public and private clouds*, allowing data and applications to be shared between them. This provides *greater flexibility and optimization of existing infrastructure, security, and compliance*. Examples include using a private cloud for sensitive data while leveraging public cloud resources for less critical operations.
