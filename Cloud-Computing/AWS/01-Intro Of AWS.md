# AWS (Amazon Web Services) Introduction

---

- It is a cloud computing platform provided by Amazon.
- It offers a wide range of cloud services including computing power, storage options, and networking capabilities.
- No need to invest in physical hardware; users can rent resources on-demand.
- AWS operates on a pay-as-you-go pricing model, allowing users to pay only for the resources they use.
- It provides scalability, flexibility, and reliability for businesses of all sizes.

---
## Key Features of AWS

- **Scalability**:  
  AWS demand ke according resources ko automatically scale kar deta hai.

- **Flexibility**:  
  Multiple operating systems, programming languages aur frameworks support karta hai.

- **Security**:  
  AWS built-in security features aur compliance certifications provide karta hai.

- **Cost Effectiveness**:  
  Pay-as-you-go model hone ki wajah se sirf used resources ka hi paisa dena padta hai.

- **Disaster Recovery**:  
  AWS backup aur recovery solutions provide karta hai taaki data safe rahe.

---

## Common AWS Services

- **Amazon EC2 (Elastic Compute Cloud)**:  
  Cloud me resizable virtual servers provide karta hai.

- **Amazon S3 (Simple Storage Service)**:  
  Data backup, archiving aur analytics ke liye scalable object storage.

- **Amazon RDS (Relational Database Service)**:  
  MySQL, PostgreSQL, Oracle jaise databases ke liye managed database service.

- **AWS Lambda**:  
  ServerLess service provide krta hain jo events ke response me code run karti hai.

- **Amazon VPC (Virtual Private Cloud)**:  
  AWS cloud ke andar isolated private network create karne me help karta hai.

---

# Important Termonology in AWS
- **Region**:  
  Geographical area jahan AWS data centers located hote hain.

- **Availability Zone (AZ)**:  
  Data center inside a region(matlab ek region ke andar multiple data centers hote hain).

- **Edge Location**:
    Global caching servers jo faster content delivery ke liye use hote hain.
